# Agent Rules

## Formatting

- **Avoid markdown tables in summaries** – Dark themes make table content difficult to read. Use lists or prose instead.
- **Lowercase comments** – Comments should be lowercase except for acronyms.
- **Check any updated file for a date and update to the current date**

## Code Quality

- **After modifying a file, review the full modified function/block for redundant or superseded code paths.** When adding logic that replaces existing behavior, remove the old code.
- **Follow the exact format of existing comments and conventions.**
